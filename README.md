Este repositório foi criado durante o curso de introdução ao **Back-end** da [Programaria](https://euprogramo.thinkific.com/certificates/hesmh8yzv9), onde aprendi os fundamentos do desenvolvimento de APIs com Node.js.

O projeto tem como objetivo colocar em prática os principais conceitos de um servidor back-end, incluindo rotas, requisições e manipulação de dados.

### 🚀 Funcionalidades:
- Criação de uma API REST simples
- Rotas para listagem, criação e atualização de dados
- Manipulação de dados em memória
- Uso do Express para criação do servidor

### 🛠️ Tecnologias utilizadas:
- Node.js
- Express
- JavaScript
